# Prem Mallappa - Personal Website

A clean, fast, and maintainable personal website built for simplicity and effectiveness.

## Philosophy: Simple + Powerful

- **Easy to maintain**: Write content in markdown
- **Fast to load**: Minimal JavaScript, optimized CSS
- **Fully customizable**: When you want control, you have it
- **No overkill**: Just what you need, nothing more

## Structure

```
├── content/          # Your posts and pages (markdown)
├── static/           # Images, CSS, JS
├── layouts/          # HTML templates (when you need custom layouts)
└── index.html        # Home page
```

## Getting Started

1. Write content in markdown files
2. Images and assets go in `static/`
3. Customize styling in `static/css/`
4. Deploy anywhere (GitHub Pages, Netlify, etc.)
